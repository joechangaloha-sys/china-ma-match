保密与安全 Confidentiality and security

分阶段披露 Staged disclosure

  1. 公开：只有卖方确认的匿名区间，不含名称、地址、客户名称或图片。Public: only seller-approved ranges.
  2. 引荐：卖方批准后，买方收到匿名简介。Introduction: anonymous teaser after seller approval.
  3. 保密协议后：信息备忘录（仍不含公司名称）。After NDA: info memo, still without the name.
  4. 卖方同意后：资料室文件与公司名称。With seller consent: data room and the company name.

技术措施 Controls

  • 每次访问资料都在服务器端检查权限，并记录查看和下载。Every document request is permission-checked and logged.
  • 按角色分权：卖方、买方、交易经理只能看到各自的事项。Role-based access per matter.
  • 上传文件视为不可信数据处理，AI 仅接收当前任务所需的最少信息。Uploads are treated as untrusted; AI gets only what a task needs.
  • 平台核验不代表对盈利、估值或产权的保证。Verification is not a guarantee of earnings, value or title.
